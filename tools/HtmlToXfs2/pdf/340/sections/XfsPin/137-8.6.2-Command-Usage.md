8.6.2 Command Usage
This section provides an example of the sequence of commands required to enter an encryption key securely. In the
following sequence, the application retrieves the keyboard secure key entry mode and associated keyboard layout
and displays an image of the keyboard for the user. It then gets the first key part, verifies the KCV for the key part
and stores it. The sequence is repeated for the second key part and then finally the key part is activated.

[part 1 master encryption key values are manually entered on the PinPad]

WFS_CMD_PIN_SECUREKEY_ENTRY command]
