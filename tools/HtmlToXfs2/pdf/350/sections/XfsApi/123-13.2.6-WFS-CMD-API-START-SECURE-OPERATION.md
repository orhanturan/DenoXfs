13.2.6 WFS_CMD_API_START_SECURE_OPERATION
Description This command is used in order for the application to indicate the intent to start a secure E2E
operation of the type where a device authenticated result is returned via the
WFS_INF_API_SECURE_QUERY command. This provides an indication to the device to start
accumulating data that will be included in the WFS_INF_API_SECURE_QUERY result.
Input Param LPWFSAPISECUREOPERATION lpSecureOperation;
typedef struct _wfs_api_secureoperation
{
DWORD dwOperation;
LPSTR lpszUniqueID;
} WFSAPISECUREOPERATION, *LPWFSAPISECUREOPERATION;
dwOperation
Describes the operation to be secured as one of the following values:
Value Meaning
WFS_API_CIM_OPCASHINTRANSACTION Start a secure E2E cash-in transaction.
lpszUniqueID
Pointer to a NULL terminated string that contains a unique ID, which will be included in the
WFS_INF_API_SECURE_QUERY result to be used in validation of the result. This value will
associate the secure operation with a specific account or transaction, but should not be easily
predictable. See the E2E Programmer's Reference document [Ref. 3] for further details about the
unique ID.
Output Param None.
Error Codes In addition to the generic error codes defined in Section 11, the following error codes can also be
generated by this command:
Value Meaning
WFS_ERR_API_KEY_NOVALUE The key to be used for generation or
validation is not loaded.
Events Only the generic events defined in [Ref. 1] can be generated by this command.
Comments None.
