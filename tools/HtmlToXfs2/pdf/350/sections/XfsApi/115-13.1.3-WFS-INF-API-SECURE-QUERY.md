13.1.3 WFS_INF_API_SECURE_QUERY
Description  This command is used to provide the host authentication to the device to securely execute an E2E
Authentication process for a GetInfo Category. In this case dwCategoryID is used to specify a
GetInfo Category for a specific service, e.g. WFS_INF_CDM_PRESENT_STATUS.
For further details see the description for WFS_CMD_API_SECURE_COMMAND.
