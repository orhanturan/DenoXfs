7.24 WFS_EXEE_CIM_INCOMPLETERETRACT
Description This execute event is sent when the WFS_CMD_CIM_RETRACT or WFS_CMD_CIM_RESET
command has completed with an error and not all of the items have been retracted. The
WFS_EXEE_CIM_INFO_AVAILABLE event reports on notes that were successfully moved
during the command prior to the failure.
Event Param LPWFSCIMINCOMPLETERETRACT lpIncompleteRetract;
typedef struct _wfs_cim_incomplete_retract
{
USHORT usReason;
} WFSCIMINCOMPLETERETRACT, *LPWFSCIMINCOMPLETERETRACT;
usReason
The reason for not having retracted items. The value is specified as one of the following values:
Value Meaning
WFS_CIM_IRRETRACTFAILURE The retract has partially failed for a reason
not covered by the other reasons listed in this
event, for example failing to pick an item to
be retracted.
WFS_CIM_IRRETRACTAREAFULL The specified retract area (see input
parameter usRetractArea) has become full
during the retract operation.
WFS_CIM_IRFOREIGNITEMSDETECTED Foreign items have been detected.
WFS_CIM_IRINVALIDBUNCH An invalid bunch of items has been detected,
e.g. it is too large or could not be processed.
Comments None.
